# Author review package

This directory contains the short, human-readable version intended for initial review by Russell Lyons.

- [`main.pdf`](main.pdf): the review note, capped at eight pages.
- [`main.tex`](main.tex): LaTeX source.
- [`author_review_email.md`](author_review_email.md): a brief email draft; it has not been sent.
- [`verify_exact.py`](verify_exact.py): dependency-free exact verification of the explicit interior Hessian bound.
- [`boundary_table.csv`](boundary_table.csv): the 32 ungrouped rational terms behind the boundary limit.
- [`verification_summary.md`](verification_summary.md): two fresh read-only review verdicts and frozen file hashes.

The note gives the information-geometric mechanism, the four-vector construction, the exact positive boundary limit, and the finite certificate at \(\varepsilon=10^{-6}\). The longer projection-boundary extension remains separate because it is not needed to audit the counterexample.
