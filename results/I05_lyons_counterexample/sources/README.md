# Original sources and direct PDF links

This directory indexes the primary and directly relevant sources used in the historical note. The repository does not mirror the external PDF files because we have not verified that every publisher or author license permits third-party redistribution. Each link below goes directly to the publisher, arXiv, or the author's own site.

The accompanying [references.bib](references.bib) is a reusable bibliography. The exact historical account and the distinction between the finite and stationary conjectures are in [history_zh.md](../history_zh.md).
